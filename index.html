Modelo Matemático

El fundamento detrás de nuestras conversiones y escalados.

Variables

  • Porciones base (PB): Para cuántas personas rinde la receta original.
  • Porciones deseadas (PD): El número total de personas para las que se desea preparar la receta.
  • Cantidad base del ingrediente (IB): La cantidad original indicada en la receta.
  • Cantidad deseada del ingrediente (ID): La nueva cantidad calculada después del escalado.

Sistema de Ecuaciones

El sistema utiliza un modelo de proporcionalidad directa. Primero calcula el factor de escala (k) a partir de la relación entre las porciones deseadas y las porciones base:

k = PD / PB

Luego ese factor se multiplica por la cantidad base de cada ingrediente para obtener la nueva cantidad requerida:

ID = k × IB

Como explicación complementaria, esta es la relación de proporcionalidad subyacente:

IB / PB = ID / PD
